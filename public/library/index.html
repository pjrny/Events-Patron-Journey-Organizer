How filling works: each workbook has one Inputs tab. Every other tab reads from it with live formulas, so you can change a number and the whole file updates. The Sources tab cites every ratio. Guidance figures are planning floors. Your licensing authority, fire marshal (AHJ) and medical provider set the final numbers.

Privacy: blank and sample files contain no names of private individuals, phone numbers, emails, PINs or vendor pricing. "My data" is read from this browser's storage (saved when you click Download Event Bible or Template Library in the simulator) and never sent to a server.
